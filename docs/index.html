Per-channel symmetric INT8 (quantization/int8.py)
scale_i = max_j(|W_ij|) / 127.0
W_q = clamp(round(W / scale), -127, 127)

Row-wise `(out_features, 1)` scaling prevents outlier weights from crushing precision across other output channels

Group-wise nibble INT4 (quantization/int4.py)
packed = q_low | (q_high << 4) # uint8
W_hat = (q_unpacked * scale) + zero

Packs two 4-bit weights per uint8 byte across 128-element groups for 4× footprint reduction
